# Shopping List Manager in C

A console-based shopping list management application developed in C as a university project. It allows users to manage shopping items, identify urgent purchases, and review a history of modifications.

## Features

- **Add items:** Add shopping items and mark them as urgent or non-urgent.
- **Remove items:** Delete items from the shopping list by name.
- **Search items:** Find a specific item and check whether it is marked as urgent.
- **Display the shopping list:** View urgent items first, followed by non-urgent items.
- **Urgency counter:** Count the number of urgent items in the list.
- **Modification history:** Keep a record of addition and deletion actions.
- **Interactive menu:** Navigate through the application's features using a console menu.

## Technologies and Concepts

- **C** — Core programming language
- **Structures (`struct`)** — Organize shopping items and history entries
- **Linked lists** — Store and manage items dynamically
- **Pointers** — Navigate and modify linked lists
- **Dynamic memory allocation** — Use `malloc()` and `free()`
- **String manipulation** — Compare and manage item names
- **Standard C libraries** — `stdio.h`, `stdlib.h`, `string.h`, and `stdbool.h`

## How to Run

### Requirements

- A C compiler, such as GCC
- A terminal or command prompt

### Compilation

Compile the source file using GCC:

```bash
gcc main.c -o shopping_list
```

### Execution

On Linux or macOS:

```bash
./shopping_list
```

On Windows:

```bash
shopping_list.exe
```

## How to Use

When the application starts, a menu provides the following options:

1. Add an item
2. Remove an item
3. Search for an item
4. Display the shopping list
5. Display the modification history
6. Exit the application

When adding an item, the user can specify whether it is urgent.
